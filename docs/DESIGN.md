# Surface contract

- Operator dashboard: desktop 1440px, tablet 900px, mobile 390px. Primary action: start a demo, then connect a LIVE room. Use a 3-column workbench, not a marketing page.
- Visual direction: employee dossier on warm paper, ink-green borders, coral incident labels, mint KPI cards. Space Grotesk for numbers/headings; self-hosted Be Vietnam Pro for Vietnamese copy.
- Main hierarchy: company status, portrait stage, incident/vote, simulator and activity log. Stage is native 540x960, scales to 1080x1920 in OBS; no admin controls, no audio by default.
- Low-poly 3D office: Three.js tilted perspective camera, original box-built furniture and characters, lighting and shadows. Office uses exactly 75% of the portrait stage height (bottom band). All critical HUD (boss HP, KPI / Cột sống / Drama gauges, drama card, Top Sếp / Top Nô Lệ Tư Bản boards, command board) sits in the top 25% band; the office fills its whole 75% band (front desk rows run under TikTok comments, but no critical HUD does); a comment-safe framing is available via `OFFICE_FRAMING.mode = "safe"` in apps/game-web/src/game/safe-zone.ts. Commands are typed without a prefix (`cafe`, legacy `!cafe` still accepted). Every employee in the snapshot (up to 50) is on stage at once: twelve sit at desks, the rest work standing; no floors or rotation. A typed command is always acted out by that viewer's own character. Room signs and employee names are HTML overlays, not tiny WebGL text. Department columns are visual grouping only. No third-party stock assets or assets from the sibling project.
- Loading: reserved stage area and connection badge. Empty: office remains visible, hint that joining the LIVE puts a viewer straight in the office (no check-in, no join command) and demo action. Error: persistent operator feedback and retry. Reconnecting: mark stale data; never pretend the room is live. Permission: token input; public stage remains read-only. Success: concise action result and server snapshot. No payments; gifts are cosmetic only.
- Reduced motion: disable CSS reveals, character motion and particles; no autoplay sound on dashboard or stage. Buttons and fields have accessible names and visible focus. Portrait is fully used; the TikTok comment area (bottom 35%) and the right-edge button column carry no critical HUD. WebGL failure shows an explicit acceleration/reload instruction instead of a blank office.
